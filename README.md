# Telecom Customer Churn Analysis (MySQL Project)

## Overview
This project analyzes telecom customer churn using SQL to identify key business insights.

## Tools Used
- MySQL Workbench

## Dataset
IBM Telco Customer Churn Dataset (7,043 records)

## Objectives
- Analyze churn patterns
- Identify high-risk customers
- Understand customer behaviour

## Key Insights
- Month-to-month contracts have highest churn
- Short tenure increases churn risk
- Payment method influences churn
